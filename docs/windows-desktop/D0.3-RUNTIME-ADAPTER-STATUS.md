## 四问

1. **读什么**：AI 仍只经 `CONTEXT_SOURCES/assembleContext` 读取；RuntimeAdapter
   只传输共享 TS 已组装的 body 和原始响应字节。
2. **写什么**：AI 结果仍经 `FIELD_REGISTRY + AdoptionSchema/adopt` 写回；
   RuntimeAdapter 不写任何业务字段。
3. **涉及哪些表生命周期**：导出、备份和后续迁移 DTO 仍由
   `PROJECT_TABLES` 派生；RuntimeAdapter 只移动文本/字节，不维护表清单。
4. **注册表是否缺登记**：本任务未新增表、字段、上下文源或 AI 动作，三个
   注册表无需且没有修改。

## 已落地

- `RuntimeAdapter` 覆盖 ai、gist、files/backup binding、secrets、clipboard、
  external、durability、distribution、updates、diagnostics。
- AI 只允许 typed chat/embedding POST；精确保留用户 `configuredBaseUrl`。为
  保持现有 Web 配置零丢失，Web 允许登记的 Vite proxy alias 与已配置的
  HTTP/HTTPS（含 LAN），拒绝未知 alias、路径穿越、userinfo、非 HTTP(S) 和
  协议相对地址；Native 自定义源必须使用 `approvalId` 并在 D1/D3 实施更严格
  私网策略。Prompt/body、SSE、retry、usage、adopt 全部留在共享 TS。
- AI/Gist/raw fetch 统一 `redirect: 'error'`；raw 只允许无 userinfo、默认端口的
  精确 `https://gist.githubusercontent.com` origin。
- SecretStore 只有 `put/has/reference/delete`；明文只进入 `put`，网络能力只接收
  opaque `CredentialId`，没有 plaintext `get`。
- open/save/backup 使用互不扩权的 purpose union；adapter 内固定 accept、MIME
  与扩展名。source document 包含 TXT/MD/CSV/PDF/DOCX，reference document
  包含 TXT/MD/EPUB，模板库使用独立 `prompt-library-json`。无 FSA 文件选择器时
  Web 回退到固定 accept 的 `<input type="file">`，并复核实际扩展名。
- AI 响应流逐 chunk 检查 AbortSignal；消费者提前结束时 best-effort cancel
  reader。目录备份在关键 await 后检查中止，写入名必须与读取规则一致，并保留
  write 主错误，不被 close 二次错误覆盖。
- diagnostics 是固定 discriminated union；clipboard/external 也是固定用途，
  不接受任意 code、字段或 URL。
- Fake 覆盖成功、用户取消、AbortSignal、timeout、permission denied、disk full。
- Web 首批接管 Gist 全链路、项目 JSON/Markdown/TXT/上下文快照输出、两处剪贴板。
- 架构守卫禁止 `src/runtime/tauri` 之外导入 Tauri API 或读取 `window.__TAURI__`。
- 明确拒绝复用 `tmp/tauri-poc` 的任意 URL `llm_proxy`。
